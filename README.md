## Projects

### Trust and Transparency in the Digital Age
A business intelligence project examining how privacy protections, knowledge and digital behaviors shape public trust in technology platforms.

Some key highlights include:
- Analyzed ~5100 U.S. adults from the Pew Research Center's American Trends Panel
- Built composite scores for digitral mistrust and privacy concerns using psychometric validation
- Used mulitple linear regression, logistic regression and 10-fold cross-validation in R
- Found that privacy literacy is a key protective factor against digital mistrust

**Tools** R
